# Submission checklist

The Flip the Switch submission consisted of a public repository, a README, and a demo video. The business-workflow entry should show a person and at least one AI agent completing a real task together through Switch.

- Publish the project folder as a public repository.
- Make sure the README includes setup steps and shows where Switch is used.
- Run the workflow in a real Switch room and record the handoff, reproduction, proposed fix, and human review.
- Add the repository and video links to the event's submission form while it is open.
- Add the genuine Wispr Flow Insights scorecard only if entering Code with Wispr.
